Count Reachula

Spooky Reachy · a friendly vampire ghost for your Reachy Mini

▶ Watch the 38-second video with sound

He lurks perfectly still, jumps up with a “BOO!” when someone walks by, fills the room with creaking doors and howling wind, and plays dramatic ghostly moves. Give him an AI key and he talks: he guesses costumes through his camera, reads spooky futures and tells three-sentence ghost stories.

Spooky, but child-friendly: a startle now and then, never gore. English & Deutsch.

Talking Count

Bring your own AI: Claude, OpenAI, xAI Grok, Gemini, OpenRouter, Mistral, Groq, Ollama or any compatible API.

Setup — pick your level

  1. Haunting, no key: in Reachy Mini Control → Applications → Discover Apps, install and start Count Reachula.
  2. Talking, one key: on the app page first set the settings PIN (setup code from the robot, see README), then choose xai for chat and speech-to-text and paste one key from console.x.ai into the chat model's API key field. Claude, OpenAI, Gemini and more work too.
  3. Vampire voice, optional: add your ElevenLabs key (permissions: Text to Speech, Voices read) and press Test the voice.

Step-by-step guide, costs and troubleshooting in the README.

Tip: put him next to the candy bowl. 🍬 Talking mode hears the room and uses the camera: read the privacy note in the README first.
