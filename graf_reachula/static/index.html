🔒 Settings PIN

Guests on your Wi-Fi can open this page too. Set a PIN (at least 6 characters) first thing: providers, keys, the voice, the wake word and switching talking on need it. Sounds, moves, scares and language stay open to everyone, and anyone can switch talking off. Forgot it? See the README for the reset command.

The first PIN needs the setup code, so a guest can't set one before you do. The Count says it when he starts (only while no PIN is set; missed it? restart the app). Or over SSH: cat ~/.config/graf_reachula/setup-code.txt. On a Reachy Mini Lite, open this page on the computer the app runs on (http://localhost:8042): no code needed there.

🎙️ Voice (optional upgrade)

Free Microsoft Edge voice by default. With your own ElevenLabs key the Count gets a real theatrical vampire voice; if ElevenLabs fails, he falls back to the free voice. Create the key at elevenlabs.io → API keys and give it the permissions Text to Speech and Voices: read (plus Speech to Text if you also want ElevenLabs to listen). Leave the voice ID empty to let the Count pick a deep voice, or paste one from your voice library.

🗣️ Talking Count (optional)

Easiest: choose xai as chat model and as speech-to-text and paste one key from console.x.ai (the speech-to-text reuses it). Each answer costs a fraction of a cent.

Without keys the Count haunts with sounds and moves and speaks only his fixed lines. With a chat model and a speech-to-text key he talks, sees costumes through the camera and tells ghost stories. Keys are stored only on your robot and are never shown again. Set a PIN above before guests arrive.
